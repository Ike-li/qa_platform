# Security Policy

## Supported Versions

本项目采用 CalVer（日历版本）滚动发布，仅最新的 `main` 分支版本受安全支持。

| Version | Supported          |
| ------------------ | ------------------ |
| main (最新 CalVer) | :white_check_mark: |
| 历史版本           | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in qa-platform, please report it by emailing viktorl@163.com.

**Please do not report security vulnerabilities through public GitHub issues.**

### What to include in your report

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Initial response**: Within 48 hours
- **Status update**: Within 7 days
- **Fix timeline**: Varies based on severity

We will acknowledge your email and send a more detailed response indicating next steps.

## Security best practices

When using qa-platform:

- Keep dependencies up to date
- Use environment variables for sensitive data
- Never commit credentials to version control
- Enable appropriate authentication mechanisms

## Disclosure policy

We follow responsible disclosure practices and will coordinate with you on the timing and content of any public disclosure.
